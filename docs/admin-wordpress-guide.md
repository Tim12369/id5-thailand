# คู่มือผู้ดูแลเว็บไซต์ / Website Administrator Guide

**สำหรับ:** เจ้าหน้าที่ที่ดูแลเนื้อหาเว็บไซต์ กองบังคับการตรวจคนเข้าเมือง 5
**ไม่ต้องมีความรู้ด้านการเขียนโปรแกรม**

คู่มือนี้อธิบายวิธีแก้ไขเนื้อหาเว็บไซต์ผ่าน WordPress ซึ่งเป็นระบบที่ท่านคุ้นเคยอยู่แล้ว

---

## 1. เข้าสู่ระบบ

1. เปิดเบราว์เซอร์ ไปที่ที่อยู่ที่ผู้ดูแลระบบแจ้งไว้ เช่น
   `https://cms.example.go.th/wp-admin/`
2. กรอกชื่อผู้ใช้และรหัสผ่านของท่าน
3. กด **เข้าสู่ระบบ (Log In)**

เมื่อเข้ามาแล้ว ท่านจะเห็นหน้าแรกของ WordPress พร้อมกล่อง
**“การจัดการเว็บไซต์ ID5”** ซึ่งมีลิงก์ลัดไปยังทุกส่วนที่ท่านต้องใช้

> **ลืมรหัสผ่าน?** กด “ลืมรหัสผ่าน” ใต้ช่องเข้าสู่ระบบ หรือแจ้งผู้ดูแลระบบ
> **อย่าใช้บัญชีร่วมกับผู้อื่น** เพื่อให้ตรวจสอบได้ว่าใครแก้ไขอะไร

---

## 1.1 วิธีที่ง่ายที่สุด: เปิดเว็บไซต์แล้วคลิกแก้ไข

ท่านไม่จำเป็นต้องหาเมนูใน WordPress เอง ให้ทำดังนี้

1. เข้าสู่ระบบ WordPress แล้วกด **แก้ไขเว็บไซต์** (เมนูซ้ายบนสุด หรือแถบสีดำด้านบน)
   หรือพิมพ์ที่อยู่เว็บไซต์ตามด้วย `/edit` เช่น `https://www.example.go.th/edit`
2. หน้าจอจะแบ่งเป็นสองส่วน
   * **ด้านขวา** คือเว็บไซต์จริง
   * **ด้านซ้าย** คือรายการส่วนต่าง ๆ ที่แก้ไขได้ในหน้านั้น
3. **ชี้เมาส์** ไปที่ส่วนที่ต้องการแก้ไขบนเว็บไซต์ด้านขวา จะมีกรอบสีน้ำเงินและปุ่ม **ดินสอ “แก้ไข…”** ปรากฏขึ้น
   กดปุ่มนั้น (หรือคลิกรายการทางซ้าย)
4. แบบฟอร์มแก้ไขจะเลื่อนขึ้นมาทับหน้าเว็บ แก้ไขแล้วกด **อัปเดต / เผยแพร่**
5. กด **กลับไปดูเว็บไซต์** หน้าเว็บจะโหลดใหม่ให้เห็นผลทันที

**ไปหน้าอื่น:** คลิกเมนูหรือลิงก์บนเว็บไซต์ด้านขวาได้ตามปกติ รายการด้านซ้ายจะเปลี่ยนตามหน้าที่เปิด

**ข้อความทุกจุดบนหน้าเว็บ** — เมนู หัวข้อ ปุ่ม คำอธิบาย — แก้ไขได้ทั้งหมด ดูหัวข้อ **8.1**

**ข้อมูลเว็บไซต์** (ชื่อเว็บไซต์ สายด่วน แบนเนอร์หน้าแรก ส่วนท้าย) แก้ไขได้ในแผงด้านซ้ายโดยตรง แล้วกด **เผยแพร่**

**ดูบนมือถือ/แท็บเล็ต:** ใช้ปุ่มรูปจอ 3 ปุ่มที่มุมล่างของแผงด้านซ้าย

**ปิดหน้าจอแก้ไข:** กด **✕** มุมบนซ้าย จะกลับไปที่เว็บไซต์จริง โดยมี **แถบสีดำด้านบน**
พร้อมปุ่ม **แก้ไขเว็บไซต์** ให้กดกลับเข้ามาแก้ไขได้ทุกเมื่อ
ผู้เข้าชมทั่วไปจะไม่เห็นแถบสีดำและปุ่มดินสอนี้

> แถบสีดำจะอยู่ประมาณ 12 ชั่วโมงหลังเข้าสู่ระบบ หากหายไป ให้เข้า WordPress แล้วกด **แก้ไขเว็บไซต์** อีกครั้ง
> ต้องการดูเว็บไซต์แบบที่ผู้เข้าชมเห็น ให้กด **ดูแบบผู้เข้าชม** ทางขวาของแถบสีดำ

หัวข้อถัดจากนี้อธิบายการแก้ไขแต่ละประเภทโดยละเอียด ซึ่งใช้ได้ทั้งจากหน้าจอนี้และจากเมนูของ WordPress

## 2. หลักสำคัญที่ต้องเข้าใจ

เว็บไซต์สาธารณะกับหน้าจอ WordPress นี้ **เป็นคนละระบบกัน**

* ท่านแก้ไขเนื้อหาใน WordPress
* เมื่อกด **เผยแพร่ (Publish)** หรือ **อัปเดต (Update)** ระบบจะส่งเนื้อหาไปยังเว็บไซต์จริงโดยอัตโนมัติ
  ภายในไม่กี่วินาที
* **เนื้อหาจะยังไม่ขึ้นเว็บไซต์จนกว่าท่านจะกดปุ่มนั้น** การกด “บันทึกฉบับร่าง” ยังไม่ถือว่าเผยแพร่

ถ้าแก้ไขแล้วเว็บไซต์ยังไม่เปลี่ยน ให้รอประมาณหนึ่งนาที แล้วกด Refresh (F5) หน้าเว็บไซต์

---

## 3. ภาษาไทยและภาษาอังกฤษ

ทุกหน้าจอทำงานแบบเดียวกัน

* **ช่องหลัก** (ชื่อเรื่องและเนื้อหา) คือ **ภาษาไทย** — ใช้ช่องนี้เสมอ
* **กล่อง “ภาษาอังกฤษ / English version”** คือฉบับภาษาอังกฤษ

**ถ้าเว้นช่องภาษาอังกฤษว่างไว้ เว็บไซต์จะแสดงภาษาไทยแทน** ไม่เกิดข้อผิดพลาดใด ๆ
ดังนั้นหากยังไม่มีคำแปล ให้เว้นว่างไว้ได้เลย อย่าใส่คำว่า “-” หรือ “ไม่มี”

## 4. เมนูต่าง ๆ ในแถบด้านซ้าย

|---|---|---|
| **ข่าวสาร** | ข่าวประชาสัมพันธ์ | หน้าแรก และหน้า “ข่าวสาร” |
| **ประกาศ** | ประกาศของหน่วยงาน | หน้าแรก และหน้า “ข่าวสาร” |
| **แจ้งเตือน** | เตือนภัย เช่น มิจฉาชีพแอบอ้าง | หน้าแรก และหน้า “แจ้งเตือน” |
| **คลังความรู้** | บทความให้ความรู้ | หน้า “คลังความรู้” |
| **คำถามที่พบบ่อย** | คำถาม-คำตอบ | หน้า “คำถามที่พบบ่อย” |
| **แบบฟอร์มดาวน์โหลด** | ไฟล์ PDF ให้ประชาชนดาวน์โหลด | หน้า “ดาวน์โหลดแบบฟอร์ม” และหน้า “เกี่ยวกับเรา” |

| **บุคลากร** | แผนผังผู้บริหาร | หน้า “เกี่ยวกับเรา” และหน้าของแต่ละฝ่าย |
| **หัวข้อ ITA** | ข้อมูลความโปร่งใส | หน้า “ITA” |

| **เนื้อหาคู่มือ** | คำอธิบาย ใคร/อะไร/ทำไม/ที่ไหน/เมื่อไร/อย่างไร ตามกลุ่มผู้ใช้ | หน้า “คู่มือ” |
| **ผลการประเมิน** | คำแนะนำหลังตอบแบบประเมิน | หน้า “คุณคือใคร?” |
| **คลังสื่อ** | รูปภาพและไฟล์ทั้งหมด | ใช้ร่วมกันทุกหน้า |

## 5. เขียนข่าวใหม่

1. เมนูซ้าย → **ข่าวสาร** → **เพิ่มใหม่**
2. พิมพ์ **หัวข้อข่าว** ในช่องบนสุด (ภาษาไทย)
3. พิมพ์เนื้อหาข่าวในช่องใหญ่ด้านล่าง
4. **ใส่รูปภาพประกอบ:** ด้านขวา กล่อง **รูปประจำเรื่อง** → **กำหนดรูปประจำเรื่อง** (ดูหัวข้อ “ใส่รูปภาพ” ด้านล่าง)
5. **เลือกหมวดหมู่:** ด้านขวา ในกล่อง **หมวดหมู่**
6. ถ้ามีฉบับภาษาอังกฤษ ให้เลื่อนลงไปกรอกในกล่อง **ภาษาอังกฤษ / English version**
7. กด **เผยแพร่ (Publish)**

ภายในไม่กี่วินาที ข่าวจะปรากฏบนหน้าแรกและหน้าข่าวสารของเว็บไซต์

**ประกาศ** และ **การแจ้งเตือน** ทำแบบเดียวกันทุกขั้นตอน จากเมนู **ประกาศ** หรือ **แจ้งเตือน**

> **ทางลัด:** เปิด **แก้ไขเว็บไซต์** ไปที่หน้าแรก หน้าข่าวสาร หน้าประกาศ หรือหน้าการแจ้งเตือน
> ใต้รายการจะมีแถบเส้นประ **“+ เพิ่มข่าว”**, **“+ เพิ่มประกาศ”** หรือ **“+ เพิ่มการแจ้งเตือน”**
> กดแล้วแบบฟอร์มจะเปิดขึ้นทันที (มีให้กดแม้ยังไม่มีรายการเลยสักรายการ)

### ใส่รูปภาพในข่าว ประกาศ และการแจ้งเตือน

ใส่รูปได้ 2 แบบ และใช้พร้อมกันได้:

**1. รูปหน้าปก** — รูปหลัก 1 รูปของเรื่องนั้น

* ด้านขวาของแบบฟอร์ม: ในข่าวคือกล่อง **รูปประจำเรื่อง** → **กำหนดรูปประจำเรื่อง**
  ในประกาศและการแจ้งเตือนคือกล่อง **รูปภาพ** → **เลือกรูปภาพ**
* เลือกจากแท็บ **คลังสื่อ** หรือแท็บ **อัปโหลดไฟล์** เพื่อเลือกรูปจากเครื่อง
* รูปนี้จะแสดงเป็นรูปเล็กในรายการ (หน้าแรก หน้าข่าวสาร หน้าประกาศ) และเป็นรูปใหญ่ด้านบนของเรื่อง
  สำหรับการแจ้งเตือน รูปจะแสดงในกรอบการแจ้งเตือนนั้นเลย

**2. รูปในเนื้อหา** — ใส่กี่รูปก็ได้ แทรกระหว่างย่อหน้า

1. คลิกในช่องเนื้อหา ตรงตำแหน่งที่ต้องการวางรูป
2. กดปุ่ม **เพิ่มสื่อ** เหนือช่องเนื้อหา
3. เลือกรูปจากแท็บ **คลังสื่อ** หรือแท็บ **อัปโหลดไฟล์** → กด **ใส่ไฟล์ลงในเรื่อง**
4. คลิกที่รูปในช่องเนื้อหาเพื่อเลือก **ชิดซ้าย / กึ่งกลาง / ชิดขวา** หรือกดรูปดินสอเพื่อใส่ **คำบรรยายใต้ภาพ** และเปลี่ยนขนาด

ไฟล์ **PDF** ก็แนบด้วยปุ่ม **เพิ่มสื่อ** ได้เช่นกัน จะแสดงเป็นลิงก์ให้ดาวน์โหลด

เมื่อกด **เผยแพร่** เว็บไซต์จะคัดลอกรูปทั้งหมดไปเก็บไว้เอง ผู้เข้าชมจึงเห็นรูปได้เสมอ
ต้องการเอารูปในเนื้อหาออก: คลิกที่รูป แล้วกดปุ่ม ✕ (หรือกด Delete) จากนั้นกด **อัปเดต**

### ปักหมุดข่าวให้อยู่บนสุด

ในกล่อง **ตัวเลือกการเผยแพร่** ติ๊ก **ปักหมุดไว้ด้านบน** ข่าวนั้นจะแสดงก่อนข่าวอื่นเสมอ

### ตั้งเวลาให้ข่าวหายไปเอง

ในกล่องเดียวกัน ช่อง **ซ่อนอัตโนมัติเมื่อพ้นวันที่** ใส่วันที่ที่ต้องการให้ข่าวหยุดแสดง
เหมาะกับประกาศที่มีกำหนดเวลา เช่น ประกาศวันหยุด

## 6. แก้ไขหรือลบเนื้อหาเดิม

**แก้ไข:** เมนูซ้าย → เลือกประเภทเนื้อหา → คลิกที่ชื่อเรื่อง → แก้ไข → กด **อัปเดต (Update)**

**ซ่อนชั่วคราวโดยไม่ลบ:** ในกล่อง **เผยแพร่** ด้านขวา เปลี่ยน **สถานะ** เป็น **ฉบับร่าง (Draft)**
แล้วกด **อัปเดต** เนื้อหาจะหายจากเว็บไซต์ทันที แต่ยังเก็บไว้ให้นำกลับมาใช้ได้

**ลบ:** กด **ย้ายไปถังขยะ** เนื้อหาจะหายจากเว็บไซต์ และยังกู้คืนได้จากถังขยะเป็นเวลา 30 วัน

**ลบจากหน้าจอ “แก้ไขเว็บไซต์” (ง่ายที่สุด):**

1. เปิด **แก้ไขเว็บไซต์** ไปที่หน้าที่มีรายการนั้น แล้วกดดินสอของรายการ (หรือคลิกชื่อรายการในแผงด้านซ้าย)
2. เหนือแบบฟอร์มทางขวาจะมีปุ่มสีแดง **ลบรายการนี้** กดแล้วยืนยัน
3. แบบฟอร์มจะปิดเอง และหน้าเว็บจะโหลดใหม่โดยไม่มีรายการนั้น

รายการที่ลบด้วยวิธีนี้จะไปอยู่ใน **ถังขยะ** เช่นกัน กู้คืนได้ภายใน 30 วัน

**กู้คืน:** เมนูซ้าย → ประเภทเนื้อหานั้น → ลิงก์ **ถังขยะ** ด้านบนของรายการ → ชี้ที่ชื่อ → **กู้คืน**
รายการจะกลับมาในสถานะเดิม — ถ้าเคยเผยแพร่อยู่ ก็จะกลับไปแสดงบนเว็บไซต์ทันทีโดยไม่ต้องกดเผยแพร่ซ้ำ

**ทำไมบางรายการไม่มีปุ่มลบ:**

* **การ์ดหน้าแรก หัวข้อคู่มือ และผลการประเมิน** มีจำนวนคงที่ตามการออกแบบของเว็บไซต์ จึงแก้ไขได้แต่ลบไม่ได้
  (ข้างชื่อจะมีข้อความ “ลบไม่ได้: รายการชุดนี้มีจำนวนคงที่”)
* **หมวดที่ยังมีรายการอยู่ข้างใน** — ดูหัวข้อ 14.1

> แนะนำให้ใช้ **ฉบับร่าง** แทนการลบ เมื่อไม่แน่ใจว่าจะต้องใช้อีกหรือไม่

## 7. เปลี่ยนรูปภาพ

### รูปของข่าว บทความ บุคลากร หรือการ์ดหน้าแรก

1. เปิดเนื้อหานั้น
2. ด้านขวา กล่อง **รูปภาพ** (ในข่าวใช้ชื่อว่า **รูปประจำเรื่อง**)
3. กด **ลบรูปภาพ** แล้วกด **เลือกรูปภาพ**
4. เลือกจาก **คลังสื่อ** หรือกด **อัปโหลดไฟล์** เพื่อใส่รูปใหม่
5. กด **อัปเดต**

**ต้องการลบรูปออกโดยไม่ใส่รูปใหม่:** กด **ลบรูปภาพ** ในกล่องเดียวกัน แล้วกด **อัปเดต**
รูปจะหายจากเว็บไซต์ภายในไม่กี่วินาที (บุคลากรที่ไม่มีรูปจะแสดงเป็นรูปเงาคนแทน)

### รูปพื้นหลังหน้าแรก (แบนเนอร์ใหญ่)

เมนูซ้าย → **ปรับแต่ง (Customize)** → **ข้อมูลเว็บไซต์ (ID5)** → **หน้าแรก — แบนเนอร์ด้านบน**
→ **รูปพื้นหลังแบนเนอร์** → กด **เผยแพร่**

### คำแนะนำเรื่องรูปภาพ

* ขนาดแบนเนอร์หน้าแรก: อย่างน้อย 1920 × 1080 พิกเซล
* ไฟล์ไม่ควรเกิน 2 MB เพื่อให้เว็บไซต์โหลดเร็ว
* ใช้ไฟล์ `.jpg` สำหรับภาพถ่าย และ `.png` สำหรับโลโก้
* ใส่ **ข้อความแทนภาพ (Alt text)** ทุกครั้ง เพื่อให้ผู้พิการทางสายตาเข้าถึงได้ และเป็นข้อกำหนดของเว็บไซต์ภาครัฐ

## 8.1 แก้ไขข้อความทุกจุดบนเว็บไซต์ (เมนู หัวข้อ ปุ่ม)

ข้อความที่ติดมากับเว็บไซต์ เช่น ชื่อเมนูด้านบน หัวข้อของแต่ละส่วน ข้อความบนปุ่ม คำอธิบายในหน้าคู่มือวีซ่า / TM30 /
รายงานตัว 90 วัน คำถามในแบบประเมินสถานะ ไปจนถึงข้อความในส่วนท้าย **แก้ไขได้ทุกข้อความ ทั้งภาษาไทยและภาษาอังกฤษ**

### วิธีแก้ไข

1. เปิด **แก้ไขเว็บไซต์** แล้วไปที่หน้าที่มีข้อความนั้น
2. **ชี้เมาส์ที่ข้อความ** จะมีกรอบเส้นประสีน้ำเงินและปุ่ม **ดินสอ “แก้ไข ข้อความ”** อยู่เหนือข้อความ กดปุ่มนั้น
3. แผงด้านซ้ายจะเปิดช่องแก้ไขของข้อความนั้น มี 2 ช่อง คือ **ภาษาไทย** และ **English**
4. พิมพ์ข้อความใหม่ แล้วกด **เผยแพร่** หน้าเว็บด้านขวาจะโหลดใหม่ให้เห็นผลภายในไม่กี่วินาที

หรือเลือกจากรายการ **ข้อความในหน้านี้** ในแผงด้านซ้าย ซึ่งเรียงตามลำดับที่ปรากฏบนหน้าเว็บ
(รวมถึงข้อความที่มองไม่เห็นทันที เช่น ชื่อบนแท็บของเบราว์เซอร์ และข้อความในเมนูมือถือ)

### หาข้อความไม่เจอ

พิมพ์คำที่ต้องการในช่อง **ค้นหาข้อความทั้งเว็บไซต์…** ระบบจะค้นจากทุกหน้า ทั้งภาษาไทยและอังกฤษ
เหมาะกับข้อความที่ไม่ได้แสดงตลอดเวลา เช่น ข้อความ “ไม่พบผลการค้นหา” หรือคำตอบของผู้ช่วย AI เมื่อระบบไม่พร้อมใช้งาน

### อยากได้ข้อความเดิมกลับมา

ใต้ช่องที่ท่านแก้ไข จะมีบรรทัด **ข้อความเดิม: …** พร้อมลิงก์ **ใช้ข้อความเดิม** กดลิงก์นั้นแล้วกด **เผยแพร่**
เว็บไซต์จะกลับไปใช้ข้อความเดิมของระบบทันที — ท่านจึงทดลองแก้ไขได้โดยไม่ต้องกลัวว่าจะกู้คืนไม่ได้

> ถ้าลบข้อความในช่องจนว่างแล้วกดเผยแพร่ ระบบจะถือว่า “ใช้ข้อความเดิม” เช่นกัน เว็บไซต์จะไม่มีช่องว่างเปล่า

### ข้อควรรู้

* **คำที่ขึ้นต้นด้วยเครื่องหมาย `:`** เช่น `:count` หรือ `:query` คือจุดที่เว็บไซต์จะใส่ข้อมูลจริงให้ (เช่น จำนวนผลลัพธ์)
  ต้องคงคำนั้นไว้ในข้อความ ถ้าลบออก ระบบจะไม่ยอมบันทึกและแจ้งเตือนให้ทราบ
* **ตัวหนา** ใช้ได้เฉพาะข้อความที่ระบบระบุไว้ใต้ช่องว่า “ข้อความนี้ใช้ตัวหนาได้” โดยพิมพ์ `<strong>คำ</strong>`
  ข้อความอื่น ๆ จะแสดงตามที่พิมพ์ทุกตัวอักษร
* **ดินสอมี 2 แบบ** — กรอบ **เส้นประ** คือ “ข้อความ” (แก้ในแผงด้านซ้าย) ส่วนกรอบ **เส้นทึบ** คือ “รายการเนื้อหา” เช่น ข่าว
  สำนักงาน บุคลากร หมวดหมู่ (เปิดแบบฟอร์มของรายการนั้น)
* **ชื่อหมวดหมู่ ชื่อจังหวัด ชื่อหน่วยงานในผังบุคลากร** เป็นข้อมูลของ WordPress — ชี้ที่ชื่อแล้วกดดินสอ
  ระบบจะเปิดหน้าแก้ไขหมวดหมู่นั้นให้
* **ชื่อแถวในผังบุคลากร** (เช่น “รองผู้บังคับการ”) กำหนดอยู่ในข้อมูลของบุคลากรแต่ละท่าน ดินสอจะเปิดบุคลากรคนแรกของแถวนั้น
  ให้แก้ที่ช่อง “ชื่อแถว”
* สิ่งที่ **ไม่ใช่ข้อความ** และเว็บไซต์คำนวณเอง จะไม่มีดินสอ ได้แก่ ตัวเลขลำดับขั้นตอน (1, 2, 3) จำนวนผลการค้นหา
  วันที่ และปีงบประมาณ

## 10. แก้ไขเมนูนำทาง

เมนูซ้าย → **รูปแบบเว็บ (Appearance)** → **เมนู (Menus)**

1. กด **สร้างเมนูใหม่** ตั้งชื่อ เช่น “เมนูหลัก”
2. เลือกตำแหน่ง **เมนูด้านบน (Header menu)** หรือ **เมนูด้านล่าง (Footer menu)**
3. เพิ่มรายการด้วย **ลิงก์ที่กำหนดเอง (Custom Links)** โดยใส่ที่อยู่และชื่อเมนู
4. ลากเพื่อจัดลำดับ
5. ถ้าต้องการชื่อภาษาอังกฤษ ให้กางรายการนั้นออก แล้วกรอกช่อง
   **ชื่อเมนูภาษาอังกฤษ (English label)**
6. กด **บันทึกเมนู**

> **สำคัญ:** ตราบใดที่ท่าน **ยังไม่ได้สร้างเมนู** เว็บไซต์จะใช้เมนูเดิมที่ตั้งไว้อยู่แล้ว
> ซึ่งทำงานถูกต้องทุกประการ ดังนั้น **หากไม่จำเป็นต้องเปลี่ยนเมนู ก็ไม่ต้องทำขั้นตอนนี้เลย**
>
> เมื่อสร้างเมนูแล้ว เมนูของท่านจะแทนที่เมนูเดิมทั้งหมด จึงต้องใส่ทุกรายการที่ต้องการให้ครบ
> ตรวจสอบทุกลิงก์ว่าเปิดได้จริงก่อนบันทึก

## 11. แบบฟอร์มดาวน์โหลด

เมนูซ้าย → **แบบฟอร์มดาวน์โหลด**

**เปลี่ยนไฟล์ PDF เป็นฉบับใหม่:**

1. เปิดแบบฟอร์มนั้น
2. ช่อง **ไฟล์ PDF** → กด **ลบออก** → กด **เลือกไฟล์** → อัปโหลดไฟล์ใหม่
3. แก้ **เวอร์ชัน** เช่นจาก `1.0` เป็น `1.1` เพื่อให้ทราบว่าเป็นฉบับปรับปรุง
4. กด **อัปเดต**

**ช่องที่ห้ามเปลี่ยน:** ช่อง **รหัสแบบฟอร์ม** (เช่น `TM30`)
เป็นตัวเชื่อมแบบฟอร์มกับคู่มือต่าง ๆ บนเว็บไซต์ ถ้าเปลี่ยนจะทำให้ลิงก์ในคู่มือเสีย

## 13. แผนผังบุคลากร

เมนูซ้าย → **บุคลากร**

แต่ละคนมี:

* **ชื่อ-นามสกุล** (ช่องหัวข้อด้านบน), **ยศ**, **ตำแหน่ง**, และ **รูปภาพ** (ภาพประจำเรื่อง)
* **หน่วยงานในแผนผัง** (ด้านขวา) — เลือกว่าอยู่ฝ่ายใด
* **ชื่อแถว** — ระบุว่าอยู่แถวใดของแผนผัง เช่น “ผู้บังคับการ”

### เพิ่มบุคลากรในแถวที่ต้องการ (วิธีที่ง่ายที่สุด)

1. เมนูซ้าย → **แก้ไขเว็บไซต์** แล้วไปที่หน้า **เกี่ยวกับเรา** (หรือหน้าของกองกำกับการที่มีแผนผัง)
2. เลื่อนลงไปที่แผนผัง ท้ายทุกแถวจะมีช่องเส้นประ **“+ เพิ่มบุคลากรในแถวนี้”** — กดช่องของแถวที่ต้องการ
3. แบบฟอร์มจะเปิดขึ้นโดย **กรอกชื่อแถว ลำดับของแถว และเลือกหน่วยงานไว้ให้แล้ว**
   ท่านเพียงพิมพ์ **ชื่อ-นามสกุล**, **ยศ**, **ตำแหน่ง** และเลือก **รูปภาพ** (ภาพประจำเรื่อง ด้านขวา)
4. กด **เผยแพร่** แล้วกด **← กลับไปที่หน้าเว็บ** — การ์ดใหม่จะอยู่ในแถวนั้นทันที

ช่อง “+” นี้เห็นเฉพาะผู้ดูแลในหน้าแก้ไขเว็บไซต์ ผู้เข้าชมทั่วไปไม่เห็น

### เพิ่มจากเมนู “บุคลากร”

กด **เพิ่มบุคลากร** แล้ว **คลิกในช่อง “ชื่อแถว (ไทย)”** — จะมีรายการแถวที่มีอยู่ให้เลือก
เมื่อเลือกแล้ว ระบบจะกรอก **ชื่อแถวภาษาอังกฤษ** และ **ลำดับของแถว** ให้เอง
จากนั้นติ๊ก **หน่วยงานในแผนผัง** ด้านขวา แล้วกด **เผยแพร่**

> **สำคัญ:** บุคลากรที่ใช้ **ชื่อแถวเดียวกัน** จะอยู่แถวเดียวกัน
> ถ้าพิมพ์ชื่อแถวเองและต่างจากเดิมแม้แต่เว้นวรรคเดียว ระบบจะสร้างเป็นแถวใหม่
> จึงควร **เลือกจากรายการ** แทนการพิมพ์ ยกเว้นเมื่อต้องการสร้างแถวใหม่จริง ๆ

**สร้างแถวใหม่:** พิมพ์ชื่อแถวใหม่ แล้วใส่ **ลำดับของแถว** — ตัวเลขน้อยอยู่ด้านบน เช่น ผู้บังคับการ = 1, รองผู้บังคับการ = 2
**ลำดับในแถว:** ใช้ช่อง **ลำดับในแถว** ด้านขวา (ตัวเลขน้อยอยู่ซ้าย) คนที่เพิ่มใหม่จะอยู่ท้ายแถวหากไม่ได้ใส่
**ย้ายคนไปแถวอื่น:** เปิดบุคคลนั้น เลือกชื่อแถวใหม่จากรายการ แล้วกด **อัปเดต**
**ลบคนออกจากแถว:** เปิดบุคคลนั้น แล้วกด **ย้ายไปถังขยะ**

## 14. คู่มือการใช้บริการ (หัวข้อคู่มือ)

เมนูซ้าย → **หัวข้อคู่มือ**

|---|---|
| **เอกสารที่ต้องเตรียม** | รายการเอกสารที่ประชาชนต้องนำมา |
| **ขั้นตอนการดำเนินการ** | ขั้นตอนตามลำดับ |
| **สถานที่ดำเนินการ** | ไปที่ไหน หรือทำออนไลน์ที่ลิงก์ใด |

วิธีเพิ่มรายการ: กดปุ่ม **+ เพิ่ม…** ด้านล่างกล่องนั้น
วิธีจัดลำดับ: ลากที่สัญลักษณ์ขีดสามขีดด้านซ้ายของแต่ละรายการ
วิธีลบ: กด **ลบ** ที่มุมขวาของรายการนั้น

หัวข้อคู่มือมีจำนวนตายตัว ท่าน **แก้ไขได้ แต่สร้างใหม่หรือลบไม่ได้**

### คำอธิบายตามกลุ่มผู้ใช้ (เมนู “เนื้อหาคู่มือ”)

เมนูซ้าย → **เนื้อหาคู่มือ**

หนึ่งรายการ = หนึ่ง “กลุ่มผู้ใช้ + หัวข้อ” เช่น **นักท่องเที่ยว — วีซ่า**
ในแต่ละรายการมีช่องให้กรอก 6 คำถาม คือ **ใคร / อะไร / ทำไม / ที่ไหน / เมื่อไร / อย่างไร**
ทั้งภาษาไทยและภาษาอังกฤษ ใช้ตัวหนาและรายการแบบมีจุดนำได้ตามปกติ

* ช่องใดเว้นว่างไว้ หัวข้อนั้นจะไม่แสดงบนเว็บไซต์
* ประชาชนที่เลือกว่าตนเองเป็น “นักท่องเที่ยว” จะเห็นคำอธิบายชุดนี้เมื่อเปิดหัวข้อ “วีซ่า”
* **ห้ามสร้างรายการซ้ำ** สำหรับกลุ่มผู้ใช้และหัวข้อเดียวกัน ให้แก้ไขรายการเดิม
  (หากสร้างซ้ำ ระบบจะไม่เผยแพร่และแจ้งให้ทราบ)

## 14.1 หัวข้อ ITA

เมนูซ้าย → **หัวข้อ ITA**

ช่อง **เนื้อหา** ของหัวข้อ ITA เป็น **ข้อความธรรมดา** ไม่รองรับตัวหนา ลิงก์ หรือรายการแบบมีจุดนำ
ต้องเลือก **หมวด ITA** ในกล่องด้านขวาทุกครั้ง มิฉะนั้นระบบจะไม่เผยแพร่

### เลขในกรอบสี (เลขหมวดและเลขหัวข้อ)

* **กรอบสีเหลืองหน้าชื่อหมวด** คือ “เลขหมวด” และ **กรอบสีหน้าชื่อหัวข้อ** คือ “เลขหัวข้อ”
* **เว้นว่างไว้ได้** — ระบบจะใส่เลขถัดไปให้เอง (หมวด: 1, 2, 3 … / หัวข้อในแต่ละหมวด: 01, 02, 03 …)
  รวมถึงเมื่อสร้างหมวดใหม่จากช่อง **+ เพิ่มหมวด ITA ใหม่** ในหน้าเพิ่มหัวข้อ ซึ่งมีให้กรอกแค่ชื่อ
* หมวดใหม่จะถูกจัดไว้ **ต่อท้าย** หมวดเดิมโดยอัตโนมัติ
* ต้องการเลขแบบอื่น (เช่น O1) ให้พิมพ์เองได้ ระบบจะไม่เปลี่ยนเลขที่ท่านพิมพ์ และจะนับต่อตามรูปแบบนั้น
* แก้เลขหมวดภายหลังได้ที่ เมนูซ้าย → **หัวข้อ ITA** → **หมวด ITA** → คลิกชื่อหมวด → ช่อง **เลขหมวด**

### สีของหัวข้อ

ช่อง **สีของกรอบเลขหัวข้อ** เป็นช่องเลือกสี — คลิกที่ช่องแล้วเลือกสีที่ต้องการได้เลย ไม่ต้องพิมพ์ชื่อสีหรือรหัสสี

### ไอคอนของหัวข้อ

ไอคอนคือรูปเล็ก ๆ หน้าชื่อหัวข้อ ท่านเลือกได้ 3 แบบ

1. **ไม่ต้องทำอะไร (แนะนำ)** — เว้นช่องไอคอนว่างไว้ เว็บไซต์จะเลือกไอคอนที่เข้ากับชื่อหัวข้อให้เอง
   เช่น “งบประมาณ” ได้รูปเหรียญ “การจัดซื้อจัดจ้าง” ได้รูปรถเข็น “ร้องเรียน” ได้รูปกล่องข้อความ
   ถ้าเปลี่ยนชื่อหัวข้อ ไอคอนจะเปลี่ยนตามโดยอัตโนมัติ
2. **อัปโหลดรูปของท่านเอง** — ที่ช่อง **รูปไอคอน** กด **เลือกรูปภาพ** แล้วเลือกหรืออัปโหลดรูป
   รูปนี้จะแสดงแทนไอคอน แนะนำรูปสี่เหลี่ยมจัตุรัส พื้นหลังโปร่งใส (ไฟล์ PNG)
   ต้องการกลับไปใช้ไอคอน ให้กด **ลบออก** ใต้รูป แล้วกด **อัปเดต**
3. **ระบุชื่อไอคอนเอง** — พิมพ์ชื่อไอคอนจากเว็บไซต์ tabler.io/icons ในช่อง **ชื่อไอคอน** เช่น `file-text`
   ถ้าพิมพ์ชื่อที่ไม่มีอยู่จริง เว็บไซต์จะเลือกให้อัตโนมัติแทน หัวข้อจึงไม่มีทางไม่มีไอคอน

### ลบหัวข้อ ITA

เปิด **แก้ไขเว็บไซต์** → ไปที่หน้า **ITA** → กดดินสอของหัวข้อ → กดปุ่มสีแดง **ลบรายการนี้** เหนือแบบฟอร์ม
(หรือเมนูซ้าย → **หัวข้อ ITA** → ชี้ที่ชื่อ → **ถังขยะ**)

### ลบหมวด ITA

หมวดจะลบได้ **เมื่อไม่มีหัวข้อเผยแพร่อยู่ในหมวดนั้นแล้ว** เพื่อป้องกันไม่ให้หัวข้อทั้งหมวดหายจากเว็บไซต์ด้วยการกดครั้งเดียว

1. ลบหัวข้อในหมวดนั้นให้หมด หรือเปิดแต่ละหัวข้อแล้วเปลี่ยนไปอยู่หมวดอื่น
2. เปิด **แก้ไขเว็บไซต์** → หน้า **ITA** → กดดินสอที่ **ชื่อหมวด** → กดปุ่มสีแดง **ลบหมวดหมู่นี้**
   (หรือเมนูซ้าย → **หัวข้อ ITA** → **หมวด ITA** → ชี้ที่ชื่อหมวด → **ลบ**)

ถ้าหมวดยังมีหัวข้ออยู่ จะไม่มีปุ่มลบ และระบบจะบอกว่ายังเหลือกี่รายการ

> การลบหมวดเป็นการ **ลบถาวร** ไม่มีถังขยะ เมื่อลบแล้วหมวดจะหายจากเว็บไซต์ภายในไม่กี่วินาที
> หลักการเดียวกันนี้ใช้กับ **หน่วยงานในแผนผังบุคลากร** ด้วย

## 14.2 เมื่อระบบไม่ยอมเผยแพร่

หากกด **เผยแพร่** แล้วเห็นแถบสีแดงว่า
**“ยังไม่ได้เผยแพร่ — บันทึกเป็นฉบับร่างไว้ให้แล้ว”**
แปลว่ามีข้อมูลที่ต้องแก้ไขก่อน สิ่งที่ท่านพิมพ์ไว้ **ไม่หาย** ระบบเก็บเป็นฉบับร่างให้แล้ว

| ข้อความที่เห็น | วิธีแก้ |
|---|---|
| กรุณากรอก “…” | กรอกช่องนั้นให้ครบ |
| “…” ถูกใช้อยู่แล้วในรายการ “…” | รหัสซ้ำกับรายการอื่น ให้ใช้รหัสอื่น หรือไปแก้ไขรายการเดิมแทน |
| มีรายการสำหรับชุดนี้อยู่แล้ว | มีเนื้อหาคู่มือสำหรับกลุ่มผู้ใช้และหัวข้อนี้แล้ว ให้ไปแก้ไขรายการเดิม |
| กรุณาเลือก “…” (กล่องด้านขวา) | ติ๊กเลือกหมวดหรือหน่วยงานในกล่องด้านขวา |

แก้ไขแล้วกด **เผยแพร่** อีกครั้ง

## 15. สิ่งที่ท่าน **ไม่ควร** แตะ

| สิ่งที่ห้าม | เหตุผล |
|---|---|
| ช่อง **รหัส** ทุกชนิด (รหัสแบบฟอร์ม รหัสสำนักงาน) | เป็นตัวเชื่อมกับระบบอื่น ถ้าเปลี่ยนลิงก์จะเสีย |
| ช่อง **“การ์ดนี้คือ”**, **“หัวข้อนี้คือ”**, **“ผลนี้ใช้กับสถานะ”** | กำหนดว่าเนื้อหาไปปรากฏที่ใด ถ้าเปลี่ยนจะไปผิดที่ |
| **ลิงก์ถาวร (Permalink)** ของข่าวที่เผยแพร่แล้ว | เป็นที่อยู่หน้าเว็บจริง ถ้าเปลี่ยน ลิงก์เดิมที่คนแชร์ไว้จะเปิดไม่ได้ |
| เมนู **ปลั๊กอิน (Plugins)** และ **ธีม (Themes)** | อาจทำให้เว็บไซต์เสียหาย — บัญชีผู้ดูแลเนื้อหาจะไม่เห็นเมนูเหล่านี้อยู่แล้ว |
| **การตั้งค่า → การเชื่อมต่อเว็บไซต์ ID5** | เป็นค่าทางเทคนิค ถ้าแก้ เนื้อหาจะหยุดส่งไปเว็บไซต์จริง |
| **การตั้งค่า → ลิงก์ถาวร (Permalinks)** | ถ้าเปลี่ยน ระบบส่งเนื้อหาจะหยุดทำงาน |

**หากไม่แน่ใจว่าสิ่งใดทำอะไร ให้ถามผู้ดูแลระบบก่อนแก้ไข**

## 16. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| แก้ไขแล้วเว็บไซต์ยังเหมือนเดิม | ท่านกด **เผยแพร่/อัปเดต** แล้วหรือยัง? รอ 1 นาที แล้วกด Ctrl+F5 ที่หน้าเว็บไซต์ |
| ข่าวไม่ขึ้นหน้าแรก | ตรวจสอบว่าสถานะเป็น **เผยแพร่แล้ว** ไม่ใช่ **ฉบับร่าง** และวันที่เผยแพร่ไม่ใช่วันในอนาคต |
| รูปภาพไม่ขึ้น | ตรวจว่าได้ตั้งเป็น **ภาพประจำเรื่อง** แล้ว ไม่ใช่แค่แทรกในเนื้อหา |
| กด “ดูเรื่อง” แล้วไปหน้าข่าวรวม ไม่ใช่ข่าวที่เพิ่งเขียน | เป็นเรื่องปกติ ลิงก์นี้พาไปหน้าข่าวของเว็บไซต์จริง ให้มองหาข่าวของท่านในรายการ |
| ไม่มีปุ่ม “ดูก่อน (Preview)” | ระบบนี้ไม่มีการดูก่อน ให้ **บันทึกฉบับร่าง** ไว้ก่อน แล้วกด **เผยแพร่** เมื่อพร้อม |
| เลือกไฟล์แบบฟอร์มแล้วไม่เห็นไฟล์ที่ต้องการ | ช่องไฟล์แบบฟอร์มรับเฉพาะไฟล์ **PDF** เท่านั้น |
| อัปโหลดรูปไม่ได้ | ไฟล์อาจใหญ่เกินไป ลองย่อขนาดให้ต่ำกว่า 2 MB |
| ภาษาไทยแสดงเป็นเครื่องหมายแปลก ๆ | อย่าคัดลอกจาก Word โดยตรง ให้วางแบบ **ข้อความธรรมดา** (Ctrl+Shift+V) |
| เผลอลบเนื้อหา | เมนูนั้น → แท็บ **ถังขยะ** → **กู้คืน** (ภายใน 30 วัน) |
| ลืมว่าแก้อะไรไป | เปิดเนื้อหานั้น → กล่อง **เผยแพร่** → **การแก้ไข (Revisions)** เพื่อดูและย้อนกลับได้ |

หากยังแก้ไม่ได้ ให้แจ้งผู้ดูแลระบบ พร้อมบอกว่า **ทำอะไรอยู่** และ **เห็นข้อความอะไรบนหน้าจอ**
